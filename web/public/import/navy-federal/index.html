How to download Navy Federal transactions

Navy Federal's Digital Banking lets you download transaction history as a CSV or PDF file. Here's where to find it, and how to bring either file into UrBudget.

Download your transaction history

  1. Sign in to Digital Banking on a computer and select the account.
  2. Choose Download. It's at the right of the screen, next to Transaction History.
  3. Pick CSV or PDF and the dates since your last import.

Which file to take

  • CSV for the file import. It's a list of transactions UrBudget can read directly, with every row shown in the preview before anything is saved.
  • PDF for the assistant. A PDF is a document rather than a transaction file, so the file import can't read it, but the assistant can turn it into the same preview.
  • One account at a time. Download checking, savings and each card separately, and import each into its own account in UrBudget, so transfers between them line up.

Bring it into UrBudget

For the CSV, set Dates in the file to the order it uses: 10/31/2026 is month/day/year. Then choose Import file on your Navy Federal account and check the preview; the import guide has every step, and what the assistant sends to your AI provider when it reads a statement.

If something looks wrong

  • Purchases show up as money coming in. The CSV writes them as positive amounts. Tick Purchases are positive (UrBudget 1.0.3 and later) and preview again.
  • The file import won't take the PDF. It reads CSV, OFX, QFX and QIF files only. Attach the PDF to the assistant instead.

Budget with your Navy Federal file

Free on Windows and macOS. File import needs no bank connection. Optional SimpleFIN bank sync is available for supported US and Canadian institutions.
